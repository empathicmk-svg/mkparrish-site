# MK (@mkeezieee) × Mercedes-Benz of Smithtown — Pink Bow October

Images and videos are in `output/mercedes-smithtown/`. To rebuild them, run
`node marketing/mercedes-smithtown/build.mjs`.

**The idea:** every Mercedes-Benz on the floor wears a pink bow this October
for Breast Cancer Awareness Month. Each post connects its bow to the cause and
names the model. Each one ends with a call to action for that platform.

**Before posting**
- Check each model name against the window sticker. Names are inferred from
  the photos, so confirm the CLA, AMG E-Class, AMG GLE, AMG GT 4-Door,
  AMG GLC Coupé and GLB.
- Check the store's social-media rules for using the Mercedes-Benz and
  Competition Automotive Group names on a personal account.
- These posts make no donation claims. If the store or Competition Automotive
  Group is fundraising, add it ("$X from every delivery goes to …").
- Confirm the store number before using it. Public listings show
  (877) 862-7343 for 630 Middle Country Rd, St. James, NY 11780.

**Facebook setup:** post from a page with the **Send Message** button turned
on. On a personal profile, swap "Message me" for "Comment below."

**Hashtags**
- **Mercedes:** #MercedesBenz #MercedesAMG #AMG #MBofSmithtown
  #CompetitionAutoGroup #MercedesBenzUSA
- **Local:** #Smithtown #StJamesNY #LongIsland #SuffolkCounty #LongIslandCars
- **Cause:** #PinkBowOctober #BreastCancerAwarenessMonth #ThinkPink
  #EarlyDetectionSavesLives

Use 8–12 hashtags on Instagram, 3–5 on Facebook and 4–6 on TikTok.
