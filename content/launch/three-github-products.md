The story is the content. The repo is the proof. The product is the page (`/tools`).
Use these across LinkedIn, the carousel, and TikTok over one week.

Assets that ship with this series:
- **Carousel:** `content/linkedin/carousels/three-github-products.json` → built slides + PDF in `output/linkedin/three-github-products/`

So I fixed that. Here's what I found, and what each one became:

→ A script that builds my LinkedIn carousels from a text file → **The Authority Carousel Kit**
→ An ebook reader with one sample book in it → **a guided reading experience with checkout**
→ A video starter I cloned to learn from → **a done-for-you video sales page**

The lesson I keep relearning: you don't need a new idea. You need to ship the last one.

I put all three on one page — buy the DIY kit, hire me to build yours, or book a session.

## 2. LinkedIn — text-only follow-up (post 2, two days later)

Everyone told me to "build a SaaS."

I almost did. I had the builder-brain itch — start something new, something bigger, something with a dashboard.

Then I opened my GitHub and counted the finished things I'd never put a price on. Three of them. One was the exact tool I use to make these carousels.

The fastest money was never the new app. It was packaging the work I'd already done:
- name it
- price it
- add a payment link
- put it on one page

That's it. That's the whole "launch."

The Authority Carousel Kit is live now — the system behind every post like this one. $48, run it yourself, no Canva. Link in comments.
