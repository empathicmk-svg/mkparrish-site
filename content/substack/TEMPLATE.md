# The Margins — canonical post template

The one format every post uses, so headlines, structure, and rich-text
formatting match across the whole publication. Applied via the Substack MCP
(`substack_create_draft` / `substack_update_draft`) once `~/.substackrc` has a
real `substack.sid`.

---

## Headline convention (matching across every post)

- **Title:** sentence case (not Title Case), specific, one idea, tension-forward.
  A claim or a provocation — never a topic label. ≤ ~60 characters.
  - Good: *The conversion math founders avoid* · *What AI can't write for you*
  - Avoid: *Thoughts on copywriting* · *Marketing Tips #3*
- **Subtitle:** one sentence that names the tension or the promise. This is the
  hook that earns the open. Always present.

## Body structure (the template)

Every post follows the same skeleton so readers know the shape:

1. **The hook** — 1–3 short lines. The provocation, stated plainly. No preamble.
2. **The body** — 2–4 sections, each under a `##` header written as a mini-claim
   (not "Section 2"). Short paragraphs. One idea per paragraph.
3. **One pullquote** — a single `>` blockquote carrying the line you'd want
   screenshotted. Exactly one per post.
4. **Rich-text elements**, used consistently:
   - **Bold** for the key term the first time it appears.
   - Numbered lists for steps/frameworks; bulleted lists for parallel points.
   - `>` blockquote only for the pullquote (not for asides).
   - A `---` divider only before the sign-off.
5. **Paywall** (paid posts only) — a `/paywall` line where the free preview ends,
   after the pullquote, before the payoff section.
6. **The sign-off footer** — one of the two below, every time.

```

```
…followed by a native Substack **Subscribe** button (`/button` → Subscribe) and:

**Paid posts (below the paywall):**


## Audience mapping

- Flagship essays, the poem, quote collections → **everyone** (free; grow the list).
- Frameworks, teardowns, templates, the conversion-math pieces → **only_paid**
  (free preview to the pullquote, then `/paywall`).
- Keep ~70% free to grow the list; the free posts do the selling.
