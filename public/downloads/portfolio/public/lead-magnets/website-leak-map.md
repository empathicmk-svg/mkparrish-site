# Website Leak Map

Use this when a site looks fine but is not converting.

## Score The Page

Rate each from 0 to 3.

1. Message clarity  
Can a stranger explain what you do, who it is for, and why it matters in 10 seconds?

2. Proof density  
Does the page prove the claim with numbers, examples, before/after, named experience, or credible specificity?

3. Next step  
Is there one obvious action for the right buyer to take now?

4. Human voice  
Does the copy sound like someone with taste and conviction, or like committee-safe filler?

## Diagnosis

- 0-4: Positioning leak. Do not redesign yet. Clarify the offer first.
- 5-8: Proof leak. The buyer understands you but does not trust the claim enough.
- 9-12: Conversion leak. Package the page into a clearer path and stronger CTA.

## Fix Order

1. Rewrite the hero so it names the buyer, outcome, and decision moment.
2. Add proof within the first two scrolls.
3. Remove secondary CTAs that compete with the main action.
4. Replace vague adjectives with concrete buyer consequences.
5. Add one low-friction next step.
