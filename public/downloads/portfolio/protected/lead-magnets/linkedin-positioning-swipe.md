# LinkedIn Positioning Swipe File

Use this when a LinkedIn profile or post sounds generic.

## Profile Headline Formulas

- I help [specific buyer] turn [messy problem] into [business outcome].
- [Role] for teams that need [strategic need] and [execution need] in the same person.
- I build [asset/system] that makes [buyer decision] easier.

## Post Hooks

- If your [asset] could belong to a competitor, it is not positioning.
- The problem is not that your copy is too quiet. It is that it does not make a decision.
- Most [category] fails because it explains the company before it earns the reader.
- I do not start with the design. I start with the sentence the buyer needs to believe.

## Profile Rewrite Checklist

- Does the first line name a buyer?
- Does the profile say what changed for that buyer?
- Is there proof within the first screen?
- Does the About section sound like a human?
- Is there one clean next step?
