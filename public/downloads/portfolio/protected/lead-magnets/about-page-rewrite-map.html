About Page Rewrite Map

Use this when an About page sounds like a resume.

The Problem

Most About pages start with the writer's chronology. Strong About pages start with the reader's trust problem.

Rewrite Structure

Name the moment that brought them here.

  1. The reader's situation

Say what you believe about the work that most competitors avoid saying.

  1. The point of view

Use only the experience that helps the reader trust the offer.

  1. Selective proof

Add one memorable line that sounds like a person, not a profile.

  1. Human texture

End with the next action: audit, samples, call, or specific download.
