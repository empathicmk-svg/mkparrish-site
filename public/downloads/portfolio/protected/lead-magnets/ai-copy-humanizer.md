# AI Copy Humanizer

Use this when AI helped draft the copy but now it sounds like everyone else.

## The Humanizer Pass

1. Add stakes  
What happens if the reader ignores this?

2. Add audience  
Who exactly is this for?

3. Add proof  
What makes the claim believable?

4. Add taste  
What would you refuse to say because it sounds generic?

5. Add friction  
What objection is the reader silently holding?

6. Add a decision  
What should the reader do next?
